# SimpleTrader — Daily ATH Scan

A daily routine for NSE/BSE equities. It scrapes two Chartink screeners, reads the live ATH Reclaim Pine strategy off TradingView Desktop, ranks each shortlisted stock by the strategy's own win rate and profit factor, and writes a dated Excel watchlist (Reclaimed / Approaching).

- Install and run: [docs/SETUP.md](docs/SETUP.md)
- How the project got here: [docs/PROJECT_HISTORY.md](docs/PROJECT_HISTORY.md)
- Design specs and plans: `docs/superpowers/`
- Run it: open Claude Code in this folder and type `/daily-ath-scan`
